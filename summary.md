# **Project Report Summary: Student Grade Management System**

The **Student Grade Management System** is a console-based application developed in C++ to efficiently manage student and teacher data using **Object-Oriented Programming (OOP) concepts**. The system allows teachers to add, view, and edit student records, automatically calculate total marks, average percentages, and assign grades based on predefined criteria. Teacher records, including subjects and salaries, can also be managed seamlessly.

This project demonstrates core **OOP principles**: **inheritance**, where `Student` and `Teacher` classes inherit from a common `Person` base class; **encapsulation**, by keeping sensitive data private; **polymorphism**, via a virtual `showDetails()` function that behaves differently for students and teachers; and **abstraction**, by providing simple functions for interacting with the system. Data persistence is ensured through **file handling**, storing all records in text files for retrieval between sessions.

The system is user-friendly, with a **menu-driven interface** for easy navigation, formatted output for readability, and modular design for maintainability. It provides a **reliable, accurate, and professional solution** for managing academic data, while also serving as a clear demonstration of practical OOP applications in C++.
